# My Games

A collection of games I've built.

## Games

- **Pong** - Classic arcade game against AI
- **8-Ball Pool** - 2D top-down 8-ball pool for 2 players
- **Smash Arena** - Platform fighter against AI with selectable characters and arenas
- **Pocket World Cup** - Slingshot drag-and-flick football game with real-time 2D physics and synthetic sound effects

## Development
